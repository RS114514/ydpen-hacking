# 2026-11-17

## 三代词典笔（有道 X6 Pro / RK3566）系统镜像导出 + Docker 虚拟环境

- 设备经 ADB（序列号 2C11200001902234）连接，`adb shell` 即 root；系统是 Buildroot 2018.02 的嵌入式 Linux（非 Android），glibc 2.29 + Qt + weston 8.0.0，固件 3.4.5。
- 导出物落在 `/Volumes/500GB/Ydpen/三代笔/`：`system_a.img`(1.25G)、`boot_a.img`、`recovery.img`、`rootfs.tar.gz`(593M)、`device_info.txt`、`SHA256SUMS.txt`、`README.md`、`docker/`。
- 关键坑：这台笔上 `adb exec-out` 报 `error: closed`，二进制流拉不动 → 改用「笔上 dd 到 /userdisk → adb pull」。adb pull 实测约 7.5 MB/s。
- 用户强调笔上空间紧张：导出后已 `rm -rf /userdisk/__export`（3.6G → 1.7G）。以后凡是往笔上写临时大文件，收尾必须清。
- Docker（OrbStack，linux/arm64 原生）方案：
  - `docker import rootfs.tar.gz ydpen-dict3:3.4.5` → `docker/build.sh` 构建 `ydpen-dict3:env-v3.4.5`。
  - 笔上 weston 只编了 drm/wayland 后端，从 Debian bullseye weston 8.0.0（snapshot.debian.org 取 20200302T160844Z）抠出 `headless-backend.so`/`fbdev-backend.so` 补进镜像 → 容器里可起无头 weston。
  - 500GB 是 exFAT，macOS 会生成 `._*` AppleDouble 文件，buildkit 因 xattr 报 `operation not permitted` → 构建上下文先复制到本机磁盘（build.sh 已内置）。
  - 验证：`doom_port/build/doom_ydpen` 在容器里完成 wayland 连接 + configure + 主循环（需把 libffi.so.8、libwayland-client 0.21 放进同目录并设 LD_LIBRARY_PATH）。
  - 已知限制：`set_fullscreen` 会让 headless weston 的 desktop-shell 崩（客户端 "configure wait failed: Broken pipe"）→ 测试用窗口模式（如 `DOOM_LAYOUT=window`）；无 GPU/EGL、无声卡/触摸；`/uresource` 未导出。
