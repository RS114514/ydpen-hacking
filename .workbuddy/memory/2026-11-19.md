# 2026-11-19 三代笔 PVZ：UI 重做 + 取景板实时拖动

## 用户反馈
1. 笔上按钮太丑（灰色方块 + 大号点阵字）。
2. 右上取景板当触控板用太卡：滑动时画面不实时移动，手指抬起才动。

## 根因与修复
- **拖动不实时**：取景板拖拽原是"绝对映射 + 固定裁剪框"，画面天然静止；
  抬手时 `release()` 里补了一次 `move()`，所以"抬起才动"。
  改成相对位移 + 以准星为中心的裁剪框逐帧跟随（`pen_view.cpp`）。
- **输入路径兜底**：同时处理合成鼠标事件和 SDL finger 事件（`Input.cpp` 的
  `PenRoute`），用 `gPenLastFingerTick` 去重，防双份处理。
- **UI 全套重做**（GLInterface.cpp）：PenRoundFill/PenBubble/PenSlot/PenSunIcon/
  PenBrackets/PenCrosshair/PenTextC；新布局见 `pen_view.hpp` 的 `pen::layout`。
- **重要 GL 知识**：TRIANGLE_FAN 不自动闭合，扇形末尾必须补回 p0，
  否则顶部缺一块楔形（纯色上是"信封盖"伪影）。这个 bug 在渐变按钮上被掩盖。
- `tests/test_pen_layout.cpp` 增加相对拖拽与控件不重叠断言，212933 项全过。

## 无屏验证体系（设备屏幕/输入被并行会话占用时也能干活）
- `PVZ_UI_SHOT=<帧号>`：游戏自导出合成帧为 PPM（RGBA→RGB 逐像素转换，别整行拷贝）。
- `dev.sh headless 名字 [PVZ_PRIM] [帧号]` 一条命令出图。
- `PVZ_UI_DEMO=1` 喂假数据拍版式；`PVZ_PRIM=1..4` 逐层隔离绘制。
- `PenFrameStats` 每 600 帧打 fps/avg/worst。

## 环境注意
- 这台笔同时被"死神VS火影"(bvn36/ruffle) 会话使用，会互相抢屏幕、
  触控注入被 input-event-daemon 挡住（自写 evdev 读取器收不到注入事件）。

- exFAT 用户盘构建会写出 AppleDouble 污染 file(GLOB)，构建前要清理（已在脚本内）。

## BVN 移植：内存攻坚（凌晨会话）
- font1.xml 尾部 4 字节 `\0`（解密 padding 残留）→ AS3 Error #1088 卡加载 (2/4)。strip 后错误归零。教训：decrypt_assets_fast.py 对 .x 输出要 rstrip(b'\x00')。
- 笔 swappiness=0 是 OOM 主因之一；zram0 512MB 有效（246MB 存量时系统仍响应）。
- 游戏总占用 RSS635+swap155≈790MB + 系统 350MB > 1GB → zram 需扩 1GB + mmcblk1p13(1GB) 兜底。已写 device/memsetup.sh 并接入 session.sh；rssmon.sh 升级为含 smaps 归因采样。
- 拉起进程必须 setsid，否则 adbd 断开时整组 SIGTERM（rc=143）；OOM kill 是 rc=137。
- 桌面图标 OK（appid 8002026112000001，勿与 PVZ 8002026111800001 冲突）。3.6 DoSWF 外壳防盗版判死，主线 3.3。
- 会话结束时笔再次离线（OOM 后 adbd 挂了或用户拔线），待重连后：push memsetup/rssmon → 跑 smaps 归因 → 决定裁资源还是扩 swap。
