## 踩坑记录（重要，后续打包复用）
1. **设备侧 shell 片段禁用 `exit`**：device_shell 靠尾部 `__DOOM_EXIT__` 标记判定成败，
   片段里 `exit 0` 会直接退出 shell 跳过标记 → 被误判为失败。
2. **不要用 `stat -c %s`**：精简固件可能没有 stat，改用 `wc -c < file`。
3. **install.py 与 scripts/installer.py 的入口差异**：被 import 时 `__main__` 不执行，
   异常包装必须抽成 `run()`，否则玩家会看到整屏 traceback。
4. **zip 中文名**：macOS `zip` 会写成本地码页导致 Windows 乱码；用 Python `zipfile` 生成，
   非 ASCII 名自动带 UTF-8 flag(0x800)，`testzip()` 校验通过。
5. **安装器不许无限等待**：设备检测默认 150s 上限 + 所有 adb 调用带 timeout，
   非 tty 自动进 --yes 模式，绝不 input() 挂住。

## BAT 脚本体检（12:55 追加）
结论表（证据均来自字节级检查：BOM / CRLF / UTF-8 vs GBK / chcp / goto）：

| 包 | BAT 状态 | 判定 |
|---|---|---|
| DOOM 通用包 | 原为 LF 行尾 + UTF-8 中文 + chcp 65001 | **有问题，已修** |
| 半条命通用包 | CRLF + 纯 ASCII + chcp 65001 | 结构 OK，余 chcp 风险 |
| PvZ 通用包 | CRLF + 纯 ASCII + chcp 65001 | 同上 |
| 千恋万花 7z | CRLF + UTF-8 中文 + chcp，且有 goto 标签 | 大体 OK，goto+中文+65001 需观察 |
| 魔女夜宴 7z | CRLF + UTF-8 中文 + chcp，无 goto | 大体 OK |
| halflife_windows_installer（旧 v1.0.0，未发布） | **GBK** 中文且**无 chcp** | 非中文系统会炸；GBK 尾字节含 0x5C/0x7C 有解析风险 |
| dracu_riot（并行任务在建） | LF 行尾 + UTF-8 中文 + chcp | 同类问题，未动（避免干扰在写 zip） |

### 修法（DOOM 已落地）
1. **.bat 全 ASCII**：中文全部移到 .py（源码 UTF-8，与代码页无关）。
2. **.bat 里禁止 `chcp`**：Win7 cmd 在批处理中切代码页会破坏文件读取位置，脚本执行一半就退（"黑框一闪"）。改由 `installer.py` 的 `_init_console()` 调 `SetConsoleOutputCP(65001)`。
3. **CRLF 行尾 + 无 BOM**（BOM 会让首行 `@echo off` 变成乱码命令）。
4. `pause` 换成 `pause >nul` + 自印 ASCII 提示，避免切换 CP 后本地化提示乱码。
5. 结论：UTF-8 多字节字符所有字节 ≥0x80，不会与 cmd 元字符（`& | > "`）撞车；GBK 尾字节范围 0x40–0xFE 含 0x5C/0x7C，这才是"GBK 互转"出事的根因。

## 更正：解锁机制（13:40 追加，读仓库后重写）
用户当场纠正"教程别乱造"。读了 `gwjcfls-ydpen-toolkit` 的 README / SKILL.md / reference/01 / reference/04，真实机制是：

1. **两道门**：① 笔上 ADB 开关在【设置 → 法律监管】连点 10~15 下打开，**重启复位**；
   ② adbd 由 `/usr/bin/adbd_auth.sh` 存口令哈希，原厂是随机值 —— 未打补丁时任何命令只回
   `login with "adb shell auth" to continue.`
2. **所谓解锁 = OTA 中间人刷改过的固件**：OTA 明文 HTTP + 镜像不签名（只校验 MD5/SHA）+
   `policy.install.rebootUpgrade` 打开 → 等长替换口令哈希 → 刷完重启，口令变 `ydpen2026`。
3. **解锁后用法**：`adb devices` → `adb shell auth`（输口令）→ `adb shell id` 得 uid=0；
   重启后 `/tmp/.adb_auth_verified` 消失，每个会话都要重认证。
4. 机型：仓库覆盖 X6 Pro（YDPX6-2，PenOS 4.3.5）与 X7 Pro（YDPX7-1，productId/OTA key 不同）；
   **安装包只在 X6 Pro 真机验证过**，教程已改成这个口径。
