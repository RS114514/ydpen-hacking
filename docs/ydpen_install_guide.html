YDPEN GAME INSTALLER · 图文教程

把游戏装进词典笔，只需要插一根线

适用于本目录下的全部安装包：千恋＊万花、魔女的夜宴、DRACU-RIOT!、半条命 1、植物大战僵尸、DOOM。全程不需要写代码，也不需要安装 Python 或 ADB —— 这些都打包在里面了。

验证机型：有道词典笔 X6 Pro（YDPX6-2 · PenOS 4.3.5） 电脑：Windows / macOS / Linux 更新：2026-11-22

六步速通

  1. 先去解锁词典笔的 ADB 调试权限（没解锁，后面一步都走不通）。
  2. 下载游戏压缩包，完整解压到电脑硬盘上（不要留在压缩软件窗口里）。
  3. 用数据线把词典笔连电脑，笔屏幕点“允许 USB 调试”。
  4. 进解压出来的文件夹，双击对应的一键安装脚本，等它自己跑完。
  5. 看到“安装全部完成”就可以拔线。
  6. 回到词典笔桌面，点新出现的游戏图标开始玩。

01 · “解锁”到底是什么

这一步最容易被误解。词典笔不像手机，打开“开发者选项 → USB 调试”就能用；它有两道门，缺一道都装不进去。

第一道门：笔上的 ADB 开关

进入词典笔 设置 → 法律监管，对着那段文本连点 10~15 下，直到提示“ADB 调试已打开”，等 5 秒再插线。重启后就复位了，下次要重做。别反复插拔 —— 那会让 USB 设备在“出现 / 消失”之间跳，adb devices 只会显示空或者 offline。

第二道门：adbd 的登录口令

系统里的 adbd 由 /usr/bin/adbd_auth.sh 把关，存的是厂商随机生成的口令哈希。没打过补丁的笔，你连上去执行任何命令，只会得到一句：

login with "adb shell auth" to continue.

而原始口令是随机的，没有公开值。所以“插上线直接装”在一台没折腾过的笔上，必然失败。

“解锁”实际做的是什么

不是勾一个开关，而是让笔自己刷一个改过的固件镜像：把 adbd 的登录口令替换成已知口令，其余内容做等长替换、镜像大小不变。刷完重启，口令固定为 ydpen2026。

原理 这条链路成立靠三个同时满足的条件：OTA 接口走明文 HTTP、固件镜像不签名（只校验 MD5/SHA）、校验值与升级策略都在可伪造的响应里。仓库 reference/04-ota-firmware.md 有完整说明与回滚方式。
完整步骤 解锁的脚本、命令与排错都在仓库里，不在本教程复述：
github.com/gwjcfls/ydpen-toolkit （看 README 与 reference/01-access-and-adb.md、reference/04-ota-firmware.md）

解锁之后怎么用

开机、插线，在电脑上依次执行：

adb devices
adb shell auth        # 输入口令 ydpen2026，看到 success
adb shell id          # 输出 uid=0(root) 就通了

关键细节：重启后认证状态会丢（/tmp/.adb_auth_verified 随重启消失），每个新会话都要重新 auth 一次。装游戏的脚本已经内置自动认证，你不用手动敲。

你只需要做到 确认自己能在命令行里 adb shell auth 成功、adb shell id 显示 root。剩下的交给安装脚本。

机型范围

机型范围 本目录的安装包与这份教程，只在 X6 Pro（YDPX6-2，PenOS 4.3.5）上做过真机验证。
上面那套解锁工具链同时覆盖 X6 Pro 与 X7 Pro（YDPX7-1，产品 ID、OTA 路径不同）；其余型号没有验证过，但系统同源、做法相通，可以看第 11 节自己动手移植。

03 · 解压（最容易出错的一步）

绝大多数“双击没反应 / 一闪就没了”的报错，都出在这一步。

必须做 把压缩包完整解压到电脑硬盘的普通文件夹里（比如桌面、D 盘），然后再进去双击安装脚本。
不要在压缩软件的浏览窗口里直接双击脚本运行 —— 那时文件还在压缩包内部，内置环境解不出来，必然失败。

Windows

  • .zip：右键 → 全部解压缩 即可。
  • .7z：装个 7-Zip（免费）或 Bandizip / WinRAR，右键 → 7-Zip → 提取到当前文件夹。
  • 弹出密码框时输入 rstv（全部小写，没有空格）。

macOS

  • .zip：双击即可解压。
  • .7z：用 Keka（免费）拖进去，输入密码 rstv。

两个小陷阱

  • 如果文件名末尾多了一段 .bak（例如 xxx.7z.bak），那是发布时为了躲网盘审查加的，改名把 .bak 删掉再解压。
  • 解压路径别太深、别带奇怪符号。像 D:\games\笔\doom 这种短路径最稳。

05 · 连接词典笔

  1. 用支持数据传输的 Type-C 线把笔直连电脑 USB 口。很多便宜充电线只能供电、不传数据，这是“一直找不到设备”的头号原因。
  2. 在笔上打开 ADB 开关：设置 → 法律监管 → 连点 10~15 下，看到“ADB 调试已打开”后等 5 秒，再插线。
  3. 插上后别反复插拔，给系统几秒枚举设备。直插主板 USB 口，别经过扩展坞。
  4. 装之前先跑一次检测脚本（第 04 节），它会自己判断设备在不在、认证过不过。
没有授权弹窗 这台笔没有手机那种“是否允许 USB 调试”的弹窗，认证靠 adb shell auth 口令，安装脚本会自动完成。所以看到别人教程里写“点一律允许”，在这里不适用。
Windows 首次连接 如果设备管理器里出现带黄色感叹号的设备，需要安装通用 ADB 驱动，或者让 Windows 更新自动装一次驱动，然后再插拔一次。

06 · 运行安装

双击第 04 节表格里对应的那个文件，会弹出一个黑色命令行窗口。接下来你要做的只有一件事：等它跑完，中途别关窗口。

正常会看到什么

  1. 先打印一段标题，说明本包版本与内容。
  2. 自动查找设备，找到后先做一次认证，再显示设备号；找不到会提示检查线/ADB 开关，并最多等 150 秒，超时自己退出，不会一直挂着。
  3. 逐个推送文件，每推一个会显示大小和速度。
  4. 最后出现类似“安装全部完成”的提示，窗口停在那里等你按任意键。
成功标志 看到“安装全部完成 / 全部就绪”这一行，并且没有红色报错，就算装好了。可以关窗口、拔线。
日志 安装过程的每一行都会写进安装包目录下的 install.log。装完先别删这个文件夹，出问题时它就是唯一的证据。

全自动、不问问题：给脚本加参数 --yes 即可（例如 一键安装DOOM.bat --yes），适合一次装多台设备。

07 · 装完之后

  1. 拔掉数据线，回到词典笔桌面，翻一下应该能看到新装的游戏图标。
  2. 点击图标进入游戏。第一次启动会慢几秒，属于正常现象。
  3. 存档在笔的 /userdisk/ 对应游戏目录里，重装不会清掉；安装器还会在升级前把旧存档备份到电脑上的 backup/ 文件夹。
  4. 不想玩了：删掉笔上对应的游戏目录即可，不影响系统；桌面图标可在应用管理里移除。
触控 笔上没有实体摇杆，游戏都做了屏幕触控层：左侧负责移动/转身，右侧负责开火、使用、切武器，返回键通常对应游戏内的菜单。

08 · 按现象查故障

先在后面对应你看到的现象，按里面的顺序排查。九成问题都在前三项。

双击后黑窗口一闪就没了

最常见，通常是两种原因：

  1. 在压缩包里直接双击的。把压缩包完整解压到硬盘，再进文件夹运行。
  2. 杀毒软件把内置的 python.exe 删了。检查解压目录里 tools\python\python.exe（通用包是 tools\win64\python\python.exe）还在不在；不在就把该目录加入杀毒白名单后重新解压。
一直提示“未检测到设备”
  1. 换一根确认能传数据的 Type-C 线（这条占一半以上）。
  2. 笔屏幕点亮，确认 USB 调试是开着的，并点了“允许”。
  3. 换电脑上的另一个 USB 口，别经过扩展坞。
  4. Windows：设备管理器看有没有未知设备，装通用 ADB 驱动。
adb devices 显示 offline

这是这台笔最常见的状态，基本不是线的问题，而是 ADB 开关没复位。按顺序做：拔线 → 在笔上重开 ADB 开关（设置 → 法律监管连点 10~15 下）→ 等 5 秒 → 插线 → 放着别动。反复快速插拔只会让它一直在“出现/消失”之间跳。

窗口里出现 login with "adb shell auth"

这是“连上了但没通过认证”。两种情况：

  1. 重启过笔 —— 认证状态随重启失效，重新 adb shell auth 即可；安装脚本会自动做这一步，重跑一次安装器也行。
  2. 这台笔还没打过固件补丁 —— 原厂口令是随机的，只能先按第 01 节把补丁流程走完。
解压报错 / 密码不对 / 文件损坏
  1. 密码是 rstv，全小写、无空格。
  2. 大文件下载中断很常见。对比一下文件大小是否与第 02 节表格一致，不一致就重新下载。
  3. .7z 请用 7-Zip / Keka / Bandizip，别用系统自带的老解压器。
装完了，桌面却没有图标

说明文件推进去了，但小程序没装上。重新运行一次安装脚本（可重复安装，不会丢存档）；如果还是不行，把 install.log 发给作者，里面会有 miniapp 的安装回执。

图标在，但点开闪退 / 黑屏
  1. 确认装的是 6 代 aarch64 机型；安装脚本会检查架构，装错会直接报错。
  2. 先重启一次词典笔，再点图标 —— 上一次异常退出可能残留进程。
  3. 把 install.log 和游戏目录下的 game.log 一起发出来。
Windows 提示“已保护你的电脑”

这是 SmartScreen 对未知发布者的拦截，不是病毒。点“更多信息” → “仍要运行”。安装脚本只往词典笔写文件，不改你的电脑系统。

macOS 提示“无法验证开发者”

右键点击 .command 文件 → 选“打开” → 再点“打开”。只需做一次。若仍不行，在终端里执行 chmod +x 一键安装XXX_macOS.command 后再双击。

Linux 提示 Permission denied

用 bash 一键安装XXX_Linux.sh 运行，不要直接 ./ 执行；脚本会自己处理内置运行环境的权限。

提示空间不足

清理笔上 /userdisk 里的其他游戏或录音文件。大体积 Galgame 需要 3 GB 以上余量，装到一半空间不够会中断，重装前务必先腾出空间。

09 · 真的搞不定时，带上这三样

描述“装不上”帮助有限，直接给证据最快：

  1. 安装包目录下的 install.log（整个文件）。
  2. 报错那一刻的窗口截图，或笔屏幕的照片。
  3. 你的电脑系统（Windows 10 / macOS 14 等）和词典笔型号。
说明 这些安装包是个人移植作品，作者手上设备有限，无法在每一台电脑、每一版固件上逐一验证。遇到装不上的情况，把日志发出来通常能定位得很快 —— 大部分是线、驱动、授权这一类环境问题，不是包本身坏了。

10 · 安装脚本到底做了什么

如果你在意它会不会动系统，这一节可以让你放心：

它会做的

  • 自动用口令完成一次 adb shell auth 认证（只是登录，不改口令、不改固件）
  • 在笔的 /userdisk/ 下建一个游戏目录并写入文件
  • 安装一个桌面小程序（图标）
  • 把旧存档和设置备份到你电脑的 backup/ 目录
  • 必要时在游戏目录内放一份自带运行库

它不会做的

  • 不改系统分区、不刷机、不需要 root
  • 不删你的存档和录音
  • 不联网、不上传任何数据
  • 不在你电脑上装驱动或后台常驻程序
边界 教程只覆盖“安装与排错”。设备解锁、固件升级、硬件维修不在范围内，请按官方或对应仓库的说明操作。

11 · 其他型号能用吗？以及怎么自己移植

先说结论：没有验证过。但也不用悲观 —— 有道词典笔各代用的其实是同一套系统底座，装游戏的骨架是相通的，差的是参数，不是原理。

为什么说“系统类似”

从 X6 Pro 到后续机型，跑的都是同一套 Linux 底座：Rockchip RK3562 平台 + 有道自己的 PenOS，图形走 Wayland + EGL，音频走 ALSA；小程序是自研的 Falcon / QuickJS 框架（.amr 包），不是安卓 APK。ADB 在这套系统里只是一条调试传输通道 —— adbd 被移植了上来，所以能用 adb push、adb shell，但别拿安卓手机的思路套它：这里没有 surfaceflinger、没有 APK 安装，也没有“开发者选项”。

正因为底座是同一套，miniapp_cli、/userdisk、Wayland 合成器、ADB 鉴权这些关键环节在各代之间是通的。所以一个能跑通的安装包，换到别的型号上通常不是“推倒重来”，而是“改几个参数”。

通常会不一样的，就这四处

差异点具体表现要改什么
屏幕尺寸X6 Pro 的面板是 960×480，游戏画面按 960×266 居中，上方留给状态栏分辨率常量、画面居中偏移、状态栏留白
触控坐标不同面板的报点范围不一样，同一套按键布局会错位按键布局配置（touch.cfg 一类）、坐标换算
系统库版本图形与音频栈（libwayland、libasound、libmali）的版本可能不同，直接跑会提示缺 .so替换或补上对应版本的运行库
设备标识产品 ID、OTA 路径、小程序 appid 因型号而异安装与打包参数，appid 不能和已有应用撞车

用 AI 移植，是现在最省力的路子

这套东西的门槛不在“写代码”，在“知道该改哪一个数”。而这正好是 AI 最擅长的活：

  1. 把资料交出去。让 AI 读 ydpen-toolkit 这个仓库，里面已经有 ADB 接入、小程序打包、触控换算、固件结构的分主题笔记。
  2. 把机器信息说清楚。型号、屏幕分辨率、PenOS 版本、uname -m 的输出，一并给它。
  3. 让它做“对照改”。拿现有安装包当模板，让它按你的机型改分辨率、触控布局、启动脚本路径、appid。
  4. 先验最小闭环。先跑检测脚本确认 ADB 通，再拿体积最小的包（DOOM 约 15 MB）试装，链路通了再上大包。
好消息 这类安装是用户态安装：不刷机、不改系统分区、不动引导。最坏的结果是装不上或点开闪退，把游戏目录删掉就恢复原样，试错成本很低。
但是 解锁 ADB、改固件、换分区这些属于系统级操作，风险另算。如果你手上只有一台设备、又是日常在用的，别拿它当试验田；先在旧机器或二手设备上折腾。
