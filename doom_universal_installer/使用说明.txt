======================================================================
    《DOOM》 有道词典笔 6 代 —— 全平台通用离线一键安装包 v1.0.0
======================================================================

本安装包内置全套运行环境 + 全部游戏数据，玩家电脑不需要装 Python、
不需要装 ADB、不需要命令行基础，插线双击即可。

【一键启动入口】
- Windows 电脑：双击 `一键安装DOOM.bat`（备用英文名 install_windows.bat）
  只想检测连接是否正常：双击 `检测设备连接_Windows.bat`
- macOS 电脑（Apple Silicon 与 Intel 都支持）：双击 `一键安装DOOM_macOS.command`
  （如系统提示“无法验证开发者”，右键点文件 → 打开 → 再点“打开”）
- Linux 电脑（x86_64）：终端执行 `bash 一键安装DOOM_Linux.sh`
- 电脑已有 Python 3.8+ 的任意系统：`python3 install.py`
  离线只校验安装包是否完整：`python3 install.py --verify-payload`

【安装前准备】
1. 必须把压缩包完整解压到电脑本地文件夹再运行，
   不要在压缩软件预览窗口里直接双击脚本（会提示缺少运行环境）；
2. 用支持数据传输的 Type-C 线把词典笔直连电脑 USB 口；
3. 在笔上打开 ADB 开关：设置 → 法律监管，对着那段文本连点 10~15 下，
   看到“ADB 调试已打开”后等 5 秒再插线。重启后会复位，需要重做；
   若 adb devices 显示 offline，拔线后重开一次开关再插，别反复快速插拔；
4. 设备必须已解锁（adb shell auth 口令 ydpen2026 可用）。
   没打过固件补丁的机器无法安装；本包会自动完成认证，但不会修改固件；
5. 词典笔 /userdisk 预留 80 MB 以上空间；
6. Windows 首次连接识别不到设备时，安装通用 ADB 驱动或更新系统驱动。

【安装过程说明（全程不会卡住）】
- 连接成功后自动做一次 adb shell auth 认证（只登录，不改口令、不改固件）；
- 等待设备最长 150 秒，超时会给出检查清单并安全退出，不会一直挂着；
- 所有 ADB 命令都有超时保护，失败会明确提示原因，可重复运行；
- 默认自动选择第一台设备；多台设备时可手动选择，或用 --serial 指定；
- 全自动无人值守：加参数 `--yes`（例如 `一键安装DOOM.bat --yes`）；
- 耐心天数不够可加 `--wait 300` 延长等待。

【安装做了什么】
1. 推送 DOOM 原生引擎（doom_ydpen）与第一章完整素材（doom1.wad）；
2. 部署启动/续关脚本，并设置 960x266 居中视口与触控按键层；
3. 把旧存档 .savegame/ 与 doomrc 备份到电脑本地 backup/ 目录（不覆盖进度）；
4. 安装桌面图标小程序（appid 8002026110100001）并登记系统清理白名单，
   图标不会被词典笔自动清掉；
5. 若固件缺少 wayland / alsa 运行库，自动用包内自带库兜底，不修改系统文件。

【游戏操作】
- 桌面点击【DOOM】图标启动，进入后为经典 320x200 画面居中显示；
- 触控：左侧方向/转身，右侧开火、使用、切换武器，BACK 键打开菜单；
- 有第 7 号存档时自动续关，没有则从 E1M1 开局。

【常见问题】
Q: 双击后窗口一闪就没了？
A: 多半是在压缩包里直接运行。请完整解压后，在解压出的文件夹里再双击。
Q: 提示未检测到设备？
A: 换一根支持数据传输的 Type-C 线（很多充电线不传数据）；再按 设置 → 法律监管 连点 10~15 下
   重开一次 ADB 开关；若 adb devices 显示 offline，正是这个原因。
Q: 图标装上了但点开闪退？
A: 重新运行一次安装器（可重复安装，不会丢存档）；仍失败请把 install.log 反馈。
Q: 会覆盖我的存档吗？
A: 不会。安装不删除 .savegame，且升级前会把存档备份到电脑 backup/ 目录。
