======================================================================
    《半条命 1》有道词典笔 6 代 —— 全平台通用离线一键安装包
======================================================================

本安装包内置全套运行环境（Windows / macOS / Linux 免安装版 Python 3.11
与三端 ADB 工具）以及全量游戏资源，插线即可一键安装：

【目录内一键启动入口】
- Windows 电脑：双击 `一键安装半条命.bat`（或 `install_windows.bat`）
  若只想检测连接：双击 `check_device_windows.bat`
- macOS 电脑（Apple Silicon & Intel）：双击 `一键安装半条命_macOS.command`
  （或 `install_macos.command`；如系统提示无法验证开发者，右键点“打开”即可）
- Linux 电脑（x86_64）：终端运行 `bash install_linux.sh`（或 `bash 一键安装半条命_Linux.sh`）
- 已有 Python 3.8+ 的任意系统也可直接运行：`python3 install.py`

【安装前准备】
1. 请务必将整个压缩包完整解压到电脑本地文件夹，不要直接在压缩包预览界面双击运行；
2. 用 Type-C 数据线将词典笔直连电脑 USB 接口，点亮屏幕；
3. 确认词典笔系统设置中已打开 USB 调试，如弹出授权框请点击“允许”；
4. Windows 如首次连接识别不到设备，请检查 Windows 更新中的可选驱动或安装通用 ADB 驱动。

【包内包含的游戏特性与修复】
1. 完整 Half-Life 单人战役地图、高清材质、音效与官方简体中文配音；
2. 简体中文游戏主菜单（TrueType 中文字体），并同步保留英文 ASCII 局内字幕避免乱码；
3. 暂停菜单触控十字方向键与 ESC / OK 叠层（libwl_center.so）；
4. 修复 64 位内存对齐导致的 NPC 趴地问题（hl.so / client.so）；
5. 强制配置 `r_dynamic 0` 与 `gl_overbright 0`（userconfig.d/00-pen-render.cfg），
   避免训练室 `t0a0` 及动态光导致的黑屏问题；
6. 升级安装前自动把词典笔现有 `/userdisk/halflife/valve/save/` 存档与
   `config.cfg` 备份到电脑本地 `backup/` 目录，并保留原有存档与按键配置不被覆盖。
