======================================================================
    《半条命 1》（Half-Life 1）有道词典笔 Windows 离线全量一键安装包
======================================================================

【适用对象】
本离线安装包专为学校等没有开发环境的 Windows 电脑打造：
- 零环境依赖：内置 64 位免安装便携版 Python 3.11 与 Windows 版 ADB 工具；
- 全素材内置：包含全量 750MB 官方战役地图、材质、音效、中文对白与字幕。

【核心特性与问题修复】
1. 彻底解决 NPC 趴地问题：
   全新编译支持 aarch64 实体内存对齐的 hl.so 库，黑山基地科学家与 Barney 100% 正常站立与行走。
2. 废除虚拟摇杆，改用经典正圆十字方向键（D-Pad）：
   左手区采用 1:1 正圆独立上下左右方向键，点按即走、抬手即停，支持多指同时斜向跑动。
3. 大跳修正为向前冲跳：
   点击绿色大跳键自动产生向前冲量并收腿（+forward; +jump; +duck），起跳更敏捷。
4. 消除二级启动器，实现类似 Galgame 的纯原生直开体验：
   点击词典笔桌面【半条命】图标直接一秒全屏直入游戏，首帧即是游戏画面。
5. 视口居中锁定与触控 Y 轴平移校准：
   通过 libwl_center.so 将 960×266 视口锚定在物理屏中央 (0, 107)，触控点击与按键像素 100% 精确对齐。
6. 安全保护玩家进度：
   安装器在更新前会自动将现有存档备份到电脑本地 backup/ 目录，绝不丢失存档。

【使用步骤】
1. 用 Type-C 数据线将有道词典笔连接到学校 Windows 电脑；
2. 点亮词典笔屏幕，确认已开启 USB 调试模式；
3. 将本压缩包解压到电脑任意文件夹（例如桌面或 D 盘）；
4. 双击运行【一键安装半条命1.bat】；
5. 程序将自动检测设备并极速部署引擎与素材（约需 1 分钟左右）；
6. 提示安装成功后，拔出数据线，在词典笔应用桌面点击黄色【半条命】λ 图标即可畅玩！

【操作说明】
- 移动：左下角正圆十字键（上/下/左/右）
- 动作：左上角蹲下切换（按一下蹲、再按站起）与向前大跳
- 视角：屏幕右半部分任意区域滑动转向
- 战斗：右下角开火（射击/近战）、跳跃、使用互动、换弹、切枪
- 菜单：顶部中央菜单图标可呼出原版存读档菜单
- 退出：按词典笔实体返回键自动快速存盘并退出游戏
