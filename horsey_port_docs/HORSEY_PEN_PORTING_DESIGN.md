# 《Horsey Game》有道词典笔移植与屏幕交互适配方案设计

> **项目目标**：将位于 `/Users/fuzihao/Downloads/Horsey.Game` 的游戏《Horsey Game》移植至网易有道词典笔（目标机型：YDPX6-2 / X6 Pro）。  
> **文档定位**：供后续接手的研发与移植 Agent 完整理解游戏底层架构、数据资产、系统运行约束及专为超宽屏幕定制的交互方案。

## 一、 原版《Horsey Game》深度逆向与资产画像

### 1. 二进制与引擎特征
- **可执行文件**：`Horsey.exe`（PE32+ x86_64，大小 3,413,504 字节，静态编译剥离符号表）。
- **底层渲染与驱动**：
  - **图形层**：SDL2 + OpenGL（调用了 `glGenFramebuffersEXT`, `glBindFramebufferEXT`, `glFramebufferTexture2DEXT` 等 FBO 扩展）以及 Direct3D 9 回退机制。
  - **音频层**：内置 `cute_sound` 音频引擎，配合 `stb_vorbis` 解码与 ALSA/DirectSound 播放。
  - **物理引擎**：静态链接完整开源 **Box2D** 物理引擎（二进制包含 `b2World`, `b2Body`, `b2RevoluteJoint`, `b2PrismaticJoint`, `b2RopeJoint` 等 RTTI 符号）。马匹的行走、摔倒、抽搐、相扑冲撞和四肢摆动完全由刚体与关节约束驱动（Ragdoll）。
- **默认视口与宽高比**：
  - `save/settings.xml` 中记录的默认窗口尺寸为 `winw="1374" winh="459"`。
  - **天然宽高比约为 3.0 : 1**，极其契合词典笔的超宽带鱼屏。

### 2. 游戏数据与资源结构
原版采用高度“数据驱动”的架构，所有核心逻辑与素材全部明文解包存放在 `data/` 目录：
1. **基因与程序化多刚体（Ragdoll）**：
   - `data/genes.xml`：定义了 240 种受 `ATGC` 碱基控制的显隐性基因（体型 `SIZE`、关节角度 `KNEE_MIN/MAX`、鹿角 `HAS_ANTLERS`、毛色 `BASE_BROWN`、神经同步信号 `L_LEG_SIGNAL`、步态协调 `LOCO_SYNC` 等）。
   - `data/pop.xml`：定义了各大野生种群（default, moose, tiger, giraffe, alligator, fest horse 等）的初始基因概率池。
2. **大世界地图与据点拓扑**：
   - `data/horsey.tmx`：400 × 225 瓦片（每格 32×32px）的超大地形图（`terrain.png` 256×512）。
   - 包含 20+ 个关键据点对象（`Locs`）：牧场（`home`）、赛马场（`track`）、选马场（`paddock`）、CRISPR 基因实验室（`crispr`）、相扑馆（`sumo`）、马戏团（`circus`，含跳水/杂技/大力士/怪胎秀）、胶水厂（`glue`）、酒吧（`saloon`）、套索专卖店（`car lot`）、孤僻隐士（`hermit`）等。
3. **图集与精灵表**：
   - `data/sprites.png`（512×512）+ `sprites.xml`：所有 UI 图标、指针、道具（苹果、干草、啤酒、套索、铲子、奖杯、DNA 碱基）及动作帧。
   - `data/furniture.png`（1024×512）+ `furniture.xml`：建筑内饰（CRISPR 操作台、酒吧柜台、马戏团帐篷、相扑擂台、大卡车等）。
   - `data/island.png`（994×444）：德霍西岛（De Horsey Island）鸟瞰大地图。
   - `sound/`：包含 383 个短音效与环境音（`.wav` 格式）。

## 二、 词典笔平台约束与移植技术路线评估

### 1. 设备硬件与平台约束
- **主控与系统**：Rockchip RK3562（四核 A53 @ 2.0GHz，Mali-G52 GPU，aarch64 Linux 5.10，PenOS 4.3.5）。
- **显示系统**：Weston (Wayland 合成器)，物理屏幕 **960 × 266**（顺时针旋转 90 度）。
- **小程序视口**：Falcon 引擎（QuickJS 字节码 + 裁剪版 Vue 2.6），逻辑视口推荐 **800 × 220**（最大高度限制 ≤ 220px）。
- **触控限制**：FocalTech `fts_ts`（物理 X: 0~480, Y: 0~960），经系统映射后支持触控，但纵向仅 220px 逻辑高度，手指容易误触边缘或遮挡内容。

### 2. 三条移植技术方案横向对比

| 评估维度 | 方案 A：Falcon 小程序 + C 原生物理/渲染模块（推荐） | 方案 B：独立 C++ 原生进程 + Framebuffer/Wayland 直写 | 方案 C：Box64 + Wine 模拟运行 Horsey.exe |
| :--- | :--- | :--- | :--- |
| **架构组成** | 页面用 Falcon Vue 2.6；物理模拟与马匹渲染由 `libjsapi_horsey.so` 处理 | 纯 C++ 交叉编译（SDL2/KMS + Box2D），用轻量小程序唤起 | Box64 动态翻译 x86_64 指令，Wine 模拟 Win32 API |
| **开发难度** | 中等（UI、事件、存档由 JS 处理，性能瓶颈交给 C） | 高（需自建轻量 UI 控件系统、文字排版与触控事件分发） | 极高（环境配置地狱，极易缺库崩溃） |
| **渲染性能** | 60 FPS（局部画板或软件双缓冲 Blit） | 60 FPS（全屏直写） | < 10 FPS（CPU 软解与指令翻译开销极大） |
| **UI 灵活性** | 极佳（便于针对词典笔超长屏幕做响应式布局重构） | 较差（每改一个按钮或文本都要在 C++ 重新调坐标） | 无（只能看原版不可控的桌面窗口拉伸） |
| **可行性结论** | **★★★★★ 最佳方案** | **★★★★☆ 备选方案** | **★☆☆☆☆ 不可行** |

> **建议执行方案**：采用 **方案 A**。参考项目内的 `senren_banka/native/gal_gs.c` 或 `better_video_player`，编写轻量 C 动态库编译为 aarch64，负责 Box2D 多刚体解算与局部贴图绘制，向上暴露简单的 JSAPI；外围的菜单、对话、商店、基因选择面板使用 Falcon Vue 组件开发。

## 三、 超宽带鱼屏（800 × 220）创新交互与操作体系

### 1. 核心布局哲学：“全屏无界舞台 + 左右拇指触控槽”
彻底抛弃在 220px 高度屏幕上再切分顶部/底部控制栏的传统做法，**220px 纵向空间 100% 留给游戏画面**。

### 2. 专为窄长触屏设计的创新机制

#### (1) 车辆移动与探索：“点哪走哪（Tap-to-Drive）+ 边缘巡航”
- **点地自动驾驶**：在大地图或开卡车时，点击画面任意地面，地面出现原版 `DriveDest` 靶心，卡车自动加速并寻路开往该点。
- **长按边缘巡航**：手指按住屏幕最右侧（或最左侧）边缘不放，卡车自动进入全速巡航模式，镜头自动跟焦平移，松手即停，无需频繁连续点按。
- **据点大门磁吸**：当点击落在赛马场、CRISPR 实验室、酒吧等建筑附近 30px 时，落点自动磁吸并吸附至大门（显示 `PointerEnter`），车停稳后直接进入室内。

#### (2) 动物与物品操作：“弹弓甩投（Flick-to-Toss）+ 一键召回”
- **消灭拖拽（Zero-Drag 原则）**：词典笔屏幕纵向短，按住乱蹦的马拖行 100px 以上极易断触。
- **轻拂甩投**：手指在马身上朝目标方向（如拖车、繁育室、体重秤）快速划动一小段距离（Flick），马匹会顺着物理抛物线直接被甩入目标建筑，伴随马腿乱蹬的 Box2D 刚体反应，爽快且容错率高。
- **去向托盘辅助**：轻点马匹选中，屏幕底部弹出半透明的一键去向图标（`[装入拖车]`、`[进马厩]`、`[送去赛马]`），点图标马自动走进去。
- **号角召回**：点击右手区的小号图标（`InvTrumpet`），所有走散的己方马匹自动向屏幕中央聚拢。

#### (3) 套马：“划线投掷 + 拇指连点拔河”
- **直觉抛绳**：野外遇见野生动物时，手指在马身旁向马的头部划出一条直线，套索（`Lasso`）即刻按照滑动速度与轨迹飞出。
- **博弈收绳**：套中后，右手拇指的动作大按钮立刻切为高亮的 `[收绳 / PULL]`，通过快速轻拍拇指将挣扎的马匹拉近并收入拖车。

#### (4) 抚摸与状态气泡：“身体直触 + 气泡即点”
- **直接搓澡（Scratch-to-Pet）**：在马身上来回左右划动 2 次，直接触发抚摸与安抚判定，马头冒出爱心，无需频繁切换“抚摸指针”。
- **头顶气泡即点即响应**：马匹出现饥饿（`ThoughtHungry`）或困倦（`ThoughtTired`）气泡时，直接点击气泡即可触发自动喂食（背包内有干草/苹果时自动消耗）或让马就地卧倒睡觉，省略“开背包 -> 选中道具 -> 移到马嘴”的繁琐流程。

#### (5) CRISPR 基因编辑台：“部位直选 + 老虎机滚轮”
- 原版在小窗口内滚动查看 240 条基因列表，小屏上极难翻找。
- **点部位过滤**：左侧展示实时 2D 骨骼马，点击马腿，右侧自动过滤出腿部基因（`LEG_LENGTH`, `LEG_COUNT`, `HAS_KNEE` 等 5~8 项）；点击马头，自动过滤出角、眼、耳基因。
- **滚轮式装配**：每项基因的 4 个碱基位 `[ A ][ T ][ G ][ C ]` 采用大号字块展示，点击即可用背包中收集的基因字母进行替换，左侧马匹骨骼实时响应形变，所见即所得。
