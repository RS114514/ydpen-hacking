# 有道词典笔原生 Web 投屏与远程控制系统 (ydpen_screensrv)

本方案将所有服务（画面采集、视频转码分发、触控按键事件注入、Web 前端界面）**完全打包并运行在词典笔内部**。

**电脑端不需要安装 Python、ADB、客户端或任何第三方软件**。只要词典笔连接了 Wi-Fi，电脑直接在浏览器输入词典笔的 IP 地址（例如 `http://192.168.31.30:8088`），即可看到画面并用鼠标操作触控。

---

## 一、设计特色

1. **零电脑依赖**：
   - 传统方案：电脑运行 Python 脚本，通过 ADB 建立端口映射捕获视频。
   - 本方案：由 aarch64 原生静态二进制程序直接在 Linux 内核上运行，内置高性能 HTTP 服务器，全自包含。
2. **复刻“文件互传”官方设计美学**：
   - 深度提取官方文件互传的深色卡片设计规范：`#141824` 沉浸背景、`#1c2130` 悬浮卡片、`#3a86ff` 高亮群青蓝主题。
   - 居中呈现 960×266 宽屏仿真机身外壳，配合平滑的触控涟漪动画。
3. **精准触控与物理按键支持**：
   - 鼠标点击与拖拽手势通过 Linux evdev 原生注入到 `/dev/input/event1`。
   - 经过实测 Wayland 协议校准的坐标映射，彻底杜绝颠倒反向。
   - 支持物理按键模拟（电源键唤醒/息屏、返回手势、主屏幕手势、左右滑屏）。
4. **手动开关，不开机自启**：
   - 程序放在 `/userdisk/bin/ydpen_screensrv`，平时不运行。
   - 需要时在笔上（PenTerm 终端或 ssh/adb）执行 `screen_on` 开启，`screen_off` 关闭。

## 二、部署方式（放学回来插上笔后操作）

当你把词典笔带回家并用 USB 线插到电脑上后，只需在项目目录下执行：

```bash
cd /Users/fuzihao/.gemini/antigravity/scratch/ydpen/ydpen-toolkit
./install_screen_on_pen.sh
```

脚本会自动执行：
1. 检测笔端连接并推送编译好的 `ydpen_screensrv` 程序。
2. 部署 `screen_on` / `screen_off` 手动开关脚本（不配置自启）。
3. 立即拉起服务，打印词典笔当前的 Wi-Fi IP，并自动在浏览器中打开操作界面。

## 三、日常使用方法

### 方式 1：同一 Wi-Fi 局域网无线使用（最方便，免连线）
只要电脑和词典笔连接了同一个 Wi-Fi（例如家里的路由器）：
在电脑浏览器直接访问：
```text
http://<词典笔的IP>:8088
```
*(词典笔 IP 可以在词典笔「设置 -> Wi-Fi -> 当前连接」中查看，或者在首次安装时查看脚本输出)*

### 方式 2：USB 数据线连接使用
如果所处环境没有 Wi-Fi 或网络不通，插上 USB 线运行端口映射：
```bash
adb forward tcp:8088 tcp:8088
```
然后在浏览器直接访问：
```text
http://127.0.0.1:8088
```

## 四、快捷键与交互操作

| 操作 | 对应功能 |
|---|---|
| **鼠标左键点击** | 模拟手指点击屏幕对应位置（带水波纹特效） |
| **鼠标左键拖动** | 连续拖拽手势（浏览列表、翻页滑动） |
| **鼠标右键** 或 <kbd>Esc</kbd> | 返回上一层手势 |
| **空格键** <kbd>Space</kbd> | 唤醒亮屏 / 息屏休眠 |
| <kbd>Home</kbd> 键 | 回到词典笔桌面主页 |
| <kbd>←</kbd> / <kbd>→</kbd> 方向键 | 向右/向左划动卡片 |
| **点击「🔄 旋转 180°」** | 翻转画面并联动反转触控坐标 |
| **点击「📸 截图标存」** | 瞬间将当前画面原图下载到电脑 |
