## 三、缺陷与优化项列表

### 1. [功能规格缺失] 系统设置（SYSTEM）未提供「清除所有数据（CLEAR ALL DATA）」功能
- **复现路径**：主菜单（Title） -> 点击「系统设置（SYSTEM）」呼出设置弹层。
- **所在位置**：系统全局设置模块 (`app/pages/title/title.js`)
- **实际现象**：设置弹层内目前仅包含「BGM 背景音乐（开启/关闭）」开关及「BGM 音量（＋ / －）」调节控件，未提供「清除所有数据（CLEAR ALL DATA）」按钮及高危红色警告确认弹窗。
- **预期表现**：提供数据清理入口，点击弹出高危红色警告窗口，确认后清空所有 30 个存档槽、设置参数、历史回顾记录以及通关标记。
- **严重级别**：阻塞流程（规格差异）。

### 2. [触控体验瑕疵] 台词推进轻触区域偏下时易误触常驻「轻触特写」按钮
- **复现路径**：剧情推进过程中，轻触台词文本框中下部（物理坐标 `px ≈ 240, py ≈ 300`）。
- **所在位置**：主线/个人线通用剧情推进视口 (`app/pages/game/game.js`)
- **实际现象**：由于 800×220 超宽窄屏垂直空间紧凑，文本框底部常驻的「轻触特写」按钮与台词触控热区存在边缘重合，偏下点击会误触发全屏特写模式，需再次点击左侧「退出特写」返回。
- **预期表现**：进一步优化触控热区分离度，或为特写按钮增加防误触判定距离。
- **严重级别**：触控不灵 / 体验瑕疵。

### 3. [系统级后台干扰] 词典笔原生后台常驻脚本 `bili-tap-listener` 边缘热区重叠
- **复现路径**：在右侧控制栏或屏幕左上物理区域（`240 <= px <= 305 && 10 <= py <= 200`）点击。
- **所在位置**：设备底层 `/userdisk/bin/bili-tap-listener` 常驻守护进程
- **实际现象**：该后台脚本持续监听 `event1` 触摸屏事件，在此物理坐标区间内触发时会向 `/tmp/bili_download.log` 记录日志并播放短提示音。虽不阻碍 GalGame 逻辑执行，但在靠近右侧边缘点击时存在偶发后台调用。
- **预期表现**：微应用运行期间建议屏蔽或挂起系统非关联触控监听服务。
- **严重级别**：体验优化建议。
